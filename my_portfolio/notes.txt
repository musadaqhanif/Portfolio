## Notes

### WhatsApp contact link
- The WhatsApp button on the homepage is driven by `src/constants/data/socials.js`.
- WhatsApp direct chat links use this format:
  - `https://wa.me/<internationalNumberWithoutPlus>?text=<urlEncodedMessage>`
- The number must be digits only (no `+`, no spaces): `923076297161`.
- The message is URL-encoded using `encodeURIComponent()` to avoid issues with spaces/punctuation.

### Social buttons order
- Social/contact buttons are displayed in the same order as the `Socials` array in `src/constants/data/socials.js`.

### EmailJS contact form
- The Contact form uses EmailJS via `src/services/EmailService.js`.
- Required variables (create `.env.local` and restart `npm run dev` / `yarn dev`):
  - `NEXT_PUBLIC_EMAILJS_SERVICE_ID`
  - `NEXT_PUBLIC_EMAILJS_TEMPLATE_CONTACT_ID` (used by the contact form)
  - `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY` (EmailJS dashboard → Account → API Keys → Public Key)
