# musadaq.live

Personal site and portfolio for **Musadaq Hanif** — Software Engineer &
Full-Stack Developer.

Built with Next.js (Pages Router), Tailwind CSS and static generation. No
third-party JavaScript, no tracking, no database.

---

## Running it

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build && npm start
```

Copy `.env.example` to `.env.local` and fill in the EmailJS values before the
contact form will send.

## How it is organised

```
src/
  constants/
    site.js              Canonical site URL, name, email, socials.
                         Every "this website" URL derives from here.
    copy.js              All page-level copy, in English.
    data/                Content: projects, reviews, experience, services,
                         skills, blog posts, FAQ, homepage positioning.
  components/
    common/              Seo, PageHeader, BackLink
    layouts/             Navbar, Footer, Layout shell
    views/               One folder per page; home/ holds the landing sections
  pages/                 Thin route files — SEO wrapper plus a view
  styles/globals.css     Design tokens and component classes
```

### Design system

The palette is adapted from [mhuzefa.dev](https://www.mhuzefa.dev). Note the
accent deliberately **changes hue between themes** - sky blue `#30a8f2` in
light, rose `#d9436b` in dark - which is how the source scheme is built.

Colours are defined once in `src/styles/globals.css` as **space-separated RGB
channels**:

```css
--accent: 217 79 43;
```

`tailwind.config.js` maps them through `rgb(var(--accent) / <alpha-value>)`,
which is what makes `bg-accent/10` and `border-accent/40` work. If you add a
token, add it in both places and keep the channel format — writing a hex value
there will break every opacity modifier that uses it.

Semantic names: `bg`, `surface`, `elevated`, `line`, `ink`, `muted`, `faint`,
`accent`, `accent-hover`, `accent-text`, `accent-ink`, `secondary`,
`gradient-one`, `gradient-two`. Prefer these over raw Tailwind palette colours
so light and dark stay in step.

Two accent tokens exist on purpose. `accent` is for fills, borders, dots and
glows. **`accent-text` is for accent used as running text** - the raw accent
only reaches 2.3:1 on the light background, while `accent-text` reaches 3.1:1
(light) and 6.1:1 (dark). Do not use `text-accent` for body copy.

### Adding a project

Append to `src/constants/data/portfolio.data.js`. `slug` must be unique — it is
the URL and the static path. `category` must exist in `PORTFOLIO_CATEGORIES` and
`type` in `PORTFOLIO_TYPES` (both in `portfolio.js`), or the card renders
without its label. `content` is Markdown, rendered by `react-markdown` and
styled by `.markdown-body`.

To feature a project on the homepage, add its slug to `SHOWCASE_ORDER` in
`src/components/views/home/FeaturedWork.jsx`.

## Security

**Read [SECURITY.md](./SECURITY.md) before adding any script tag.**

This site previously shipped a `<script src>` pointing at a domain owned by the
template author. When that host started serving redirect malware, so did this
site. A Content-Security-Policy now blocks JavaScript from every origin except
this one, so it cannot happen again.

Do not add `<script src="...">` for a host you do not control.

## Things worth knowing

- **Do not reintroduce a custom `splitChunks` rule for CSS.** The template
  capped CSS chunks at 50 KB; splitting an extracted stylesheet by byte size
  silently drops rules, and `.relative` and the `aspect-*` utilities went
  missing, collapsing every image container to zero height.
- **Never `import * as Icons from 'react-icons/...'`.** That defeats
  tree-shaking. It put 2.5 MB of unused icons on `/skillset`; naming each import
  brought the page from 2.67 MB to 131 kB.
- The site is **English only**. The template shipped with Indonesian as the
  *default* locale, so visitors were served Indonesian unless they asked for
  English. `/en/*` URLs permanently redirect to their unprefixed equivalents.
- `npm` is the package manager. `yarn.lock` and `bun.lockb` are gitignored so a
  CI build cannot install a different dependency tree than the tested one.
- `public/sw.js`, `workbox-*.js` and `fallback-*.js` are generated by
  `next-pwa` on every build. Do not edit them.
